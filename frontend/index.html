Website Security Scanner FAQ

What does Phish & Port Scanner check?

Phish & Port Scanner can analyze a domain, URL or IP address for phishing indicators, common open ports, DNS information and HTTP security signals.

Can I check if a website is safe?

You can use the scanner to investigate a website or URL for available phishing, DNS, port and HTTP security signals. The findings and security score can help identify issues that deserve further investigation.

What is a port scanner used for?

A port scanner checks whether selected network ports are reachable on a target. This can help identify services that may be exposed and require security review.

Does the scanner check DNS records?

Yes. The scanner can inspect available DNS information associated with the target and present relevant findings as part of the security assessment.

Does it check HTTP security headers?

Yes. HTTP analysis checks available response information and security-related headers that can provide insight into a website's security configuration.

What does the security score mean?

The security score provides a simplified 0–100 representation of findings from the available checks. It is a quick way to understand scan results, not a guarantee that a website is completely safe.

Is Phish & Port Scanner free?

The free tier provides up to three scans per month. Additional usage and features may be available through the pricing plans.

Who can use a website security scanner?

Website owners, developers, students, security learners and IT teams can use security scanning tools to investigate domains, identify exposed services and review basic web security signals.
